\section{Instrumentenverstärker}\label{sec:5}

\subsection{Aufgabenstellung}

Es wird ein Instrumentenverstärker (INA) gemäß \autoref{fig:41_schaltplan} aufgebaut und so Dimensioniert, dass mittels dem Potentiometer $R_P$ eine Spannungsverstärkung im Intervall $V_u \in [2.0, 2000]\si{\volt}$ eingestellt werden kann. Am Eingang soll eine Messbrücke angeschlossen werden, welche zwei an einem Balken angebrachten Dehnmessstreifen (DMS) betriebt. Die Hilfsspannug der Brücke soll dabei \SI{3}{\volt} betragen. Die OPVs sind intern mit \SI{12}{\volt} versorgt. Die Verstärkung soll mit $R_P$ im Endeffekt so eingestellt werden, dass eine Empfindlichkeit von \SI{100}{\milli\volt\per\newton} erreicht wird.

\subsection{Dimensionierung}

Für den Instrumentenverstärker ist die Ausgangsspannung durch die Gleichung \cite[S.~87, Gl.~4.21]{EMTPraktikum2025}
\[
	U_A = \frac{R_3}{R_4}\left(1+\frac{2R_1}{R_P}\right) (U_1 - U_2)
\]
gegeben. Um die Differenz gleichmäßig zu verstärken, werden die Widerstände $R_2$ und $R_3$ auf den gleichen Wert gewählt. Es wird $R_2 = R_3 = \SI{1}{\kilo\ohm}$ gewählt. Für $R_2$ wurden die günstig auf dem Messverstärkerbrett platzierten Werte $R_1 = \SI{10}{\kilo\ohm}$. Damit ergibt sich für die Verstärkung
\[
	V_u = \frac{U_A}{U_1 - U_2} = 1 + \frac{2 \cdot \SI{10}{\kilo\ohm}}{R_P} = 1 + \frac{\SI{20}{\kilo\ohm}}{R_P}.
\]

Nun werden die Intervallgrenzen für $R_P$ bestimmt:
\begin{itemize}[noitemsep]
	\item Für $V_u = 2.0\si{\volt}$ folgt $R_{P,\max} = \SI{20}{\kilo\ohm}$.
	\item Für $V_u = 2000\si{\volt}$ folgt $R_{P,\min} = \SI{10}{\ohm}$.
\end{itemize}

Der ungedehnte DMS weist einen Widerstand von $R=\SI{120}{\ohm}$ auf. Um die maximale Empfindlichkeit der Brücke zu erreichen, werden alle Widerstände $R=\SI{120}{\ohm}$ gewählt. Im Anschluss wird die Brücke an einem der Widerstände $R$ abgeglichen. Dazu wurde eine externe Widerstandsdekade verwendet.



\subsubsection{Statische Eigenschaften}

\paragraph{Abgleichen der Offsetspannung} Zunächst wurde festgestellt, dass der Instrumenten bei einer Eingangsdifferenzspannung von $U_{in} = 0\si{\volt}$ sofort in die Sättigung geht. Als erstes wurde grob mit den Trimpotentiometern der beiden Eingangs FET-OPs (A1, A2) die Offsetspannung eingestellt. Danach wurde fein mit dem Trimpotentiometer des Ausgangs OP (A3) die Offsetspannung auf nahezu $0\si{\volt}$ eingestellt.

Am Ausgang wurden dann $U_{A0} = \SI{0.10}{\micro\volt}$ festgestellt. 

\paragraph{Differenzspannungsverstärkung} Für die Differenzenspannug wurde mit dem Labornetzteil an $U_1=\SI{0.5}{\volt}$ und an $U_2=\SI{-0.5}{\volt}$ eingestellt, um eine Differenzspannung von $U_{0}=\SI{1}{\volt}$ zu erhalten. Am Ausgang wurde dann eine Spannung von $U_A = \SI{9.29}{\volt}$ gemessen. Daraus ergibt sich eine Differenzverstärkung von
\[A_D=\frac{U_A}{U_0} = 9.29,\]
für den Widerstandsstellwert $R_P = \SI{1}{\ohm}$.

\paragraph{Gleichtaktverstärkung} Zur Bestimmung der Gleichtaktverstärkung wurden beide Eingänge auf $U_1 = U_2 = \SI{1}{\volt}$ gesetzt. Am Ausgang wurde eine Spannung von $U_A = \SI{0.12}{\milli\volt}$ gemessen. Daraus ergibt sich eine Gleichtaktverstärkung von
\[A_G = \frac{U_A}{U_1} = \SI{120e-6}{}.\]

\paragraph{Gleichtaktunterdrückung} Setzt man die beiden Verstärkungen ins Verhältnis, so ergibt sich eine Gleichtaktunterdrückung
\[
	G_U = 20 \cdot \lg\left(\frac{A_D}{A_G}\right) = \SI{97.75}{\decibel}.
\]
